# Afterimage 3D scene prototype V7

[Open the scene](https://qzq99999.github.io/afterimage-3d-scene-prototype-v7/)

Frozen WebGPU scene prototype with animated character locomotion, sand interaction, workbench editing, game mode, and over-shoulder aiming. All scene code and assets are embedded in the standalone HTML. Use a WebGPU-capable desktop browser with hardware acceleration.

- `1`: enter or leave game mode.
- `W A S D`: move; `Shift`: run outside aiming mode.
- Move the mouse to look around; hold the right mouse button to aim.
